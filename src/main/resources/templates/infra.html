CI / CD

코드를 올리면 생기는 일

사람이 서버에 들어가서 할 일은 없어요. 기다리면 바뀐 화면이 떠요.

  1. 1 코드 푸시

    서비스마다 따로 있는 GitHub 저장소에 코드를 올려요.

  2. 2 Webhook

    GitHub가 Jenkins에 "새 코드 왔어" 하고 알려 줘요.

  3. 3 Jenkins 빌드

    Gradle·npm 으로 빌드하고 Docker 이미지를 새로 만들어요.

  4. 4 컨테이너 교체

    Docker Compose가 그 서비스 컨테이너만 새 이미지로 다시 켜요.
